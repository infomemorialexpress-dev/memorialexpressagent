# Memorial Express - Agent Portal

Independent React + Vite application for Agents to generate funeral quotes and handle language selection.

## Tech Stack
- React 19
- Vite
- React Router v7

## Getting Started
```bash
npm install
npm run dev
```
Port: `http://localhost:5173`

## Features
- 6-step FSA-compliant funeral quote funnel
- Read-only merchandise & pricing catalog access
- Real-time calculations with local sales tax and mandatory fees
- Spanish / English language toggle
